How a reading is chosen

The letters alone never decide. Every BHS token carries OSHB's morphology tag, and the parser peels modifications off the surface in a fixed order, each step reading only the tag that governs it. A trailing 𐤅 becomes "his" only if the tag says prs=3ms; it becomes "they did" only if the tag says vt=perf ps=p3 nu=pl. Where OSHB leaves a modification untagged (the participle 𐤌, every verbal ending, feminine participles), the rule below names the tags it is derived from instead.

Person prefix pfm — 𐤉 𐤕 𐤀 𐤍 (+ participle 𐤌)
Stem marker vbs — 𐤄 𐤍 𐤄𐤕 𐤕, infixed 𐤕/𐤈
Pronominal suffix prs — peeled from the end first (it is outermost)
Directional / energic uvf
Nominal ending nme — 𐤉𐤌 𐤅𐤕 𐤄 𐤕 𐤉
Verbal ending vbe — derived from vt · ps · gn · nu
Residue after the root — doubled radicals, Aramaic endings, construct 𐤉

Two safeguards run inside every step: when a suffix has several spellings (𐤉𐤌 / 𐤉𐤍 / 𐤌), the parser takes the one that leaves the Strong's root intact; and it never strips a word below two letters.

The one-meaning rule

Every prefix and suffix means one thing, wherever it appears. The morphology tags still decide where a word splits — that is what keeps the root clean and lets 𐤄𐤉𐤅 show its root 𐤄𐤉𐤄 — but the letters alone decide what the chip says. Colour keeps the tag detail (2ms vs 2fs "Your", the feminine tint on 𐤕𐤉) without spelling it out as a different word.
